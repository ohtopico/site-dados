Projetos de dados e IA, cada um com o código e os notebooks no GitHub. Os painéis publicados estão em Infográficos.

Previsão de recompra de clientes em 60 dias

Modelo que indica quais clientes de um varejo online devem comprar de novo em 60 dias, com ROC AUC de 0,73 e precisão de 0,70. Limpeza de 541 mil transações, segmentação RFM e comparação de 5 modelos sem vazamento de dados do futuro.

Python · pandas · scikit-learn · LightGBM · XGBoost

Faixa salarial na área de dados no Brasil

Classificador de faixa salarial com Random Forest sobre a pesquisa State of Data Brazil 2024 (5.217 respostas). Reagrupar as faixas em 3 macrofaixas elevou a acurácia de 31% para 71%, e um resultado de 99% causado por vazamento do alvo foi identificado e descartado.

Python · scikit-learn · GridSearchCV · imbalanced-learn · Plotly

Reconhecimento de moedas brasileiras por foto

Classificador de moedas do Real por foto, com dataset próprio de 186 imagens, segmentação com OpenCV e MobileNetV2 por transfer learning. Na fase 2, um coletor monta um dataset de fotos de leilões numismáticos rotuladas pelo grau de conservação.

Python · TensorFlow/Keras · OpenCV · Google Cloud · web scraping

Proximidade de objetos para pessoas com deficiência visual

Detecta objetos, estima a proximidade e avisa a pessoa com deficiência visual. Faz parte da pesquisa de mestrado na UFSM.

Python · visão computacional · Jupyter
