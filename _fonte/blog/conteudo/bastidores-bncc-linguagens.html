As páginas de Língua Portuguesa, Literatura e Língua Inglesa completaram a série BNCC em dados para os anos finais. Elas usam o mesmo método das páginas de Computação e Matemática, mas trouxeram duas novidades: uma fonte de dados aberta e uma estrutura de anos bem diferente.

Usar uma base aberta em vez de copiar o documento

Para Linguagens, em vez de extrair os textos do PDF da BNCC, usei a base aberta bncc.dev, mantida pela Profy com licença CC BY 4.0. Ela traz o texto oficial de cada habilidade já estruturado, com campo de atuação, prática de linguagem e objeto de conhecimento. Reaproveitar um conjunto de dados aberto e bem cuidado economiza trabalho e reduz erro de digitação, e a licença permite isso desde que a fonte seja citada, como está em cada página.

Língua Portuguesa: habilidades que valem para vários anos

Na BNCC, parte das 185 habilidades de Língua Portuguesa vale para um ano só (EF06LP, EF07LP...) e parte vale para blocos: EF69LP para os quatro anos, EF67LP para o 6º e o 7º e EF89LP para o 8º e o 9º. Em vez de repetir cada habilidade em vários anos, cada bloco virou uma coluna própria, na ordem em que entra no percurso: EF69, EF67, 6º, 7º, EF89, 8º e 9º. As ligações vão de uma coluna para a seguinte. Os fios são as práticas de linguagem, como leitura, produção de textos, oralidade e análise linguística.

Literatura: um recorte, não uma disciplina

Na BNCC, a literatura não é um componente separado: ela faz parte de Língua Portuguesa, no campo artístico-literário. A página de Literatura é um recorte com as 21 habilidades desse campo. As habilidades marcadas para "todos os campos" ficam de fora, mesmo quando servem para a literatura, para que o recorte seja reproduzível por qualquer pessoa que use a mesma regra.

Língua Inglesa e a pergunta sobre o espanhol

A Língua Inglesa tem 88 habilidades do 6º ao 9º ano, em cinco eixos. As unidades temáticas parecidas, como as várias estratégias de escrita, foram juntadas em um fio só. Uma pergunta comum é sobre o espanhol. A BNCC traz só a Língua Inglesa como língua estrangeira obrigatória no Ensino Fundamental e não tem habilidades de espanhol, então não há página para ele, e a página de Inglês explica isso.

Uma ponte com a sala de aula

Os textos dessas seis páginas também alimentam a Análise das notas da turma: quando o título de uma coluna da planilha tem o código de uma habilidade, a ferramenta mostra o texto dela. É o tipo de reaproveitamento que só acontece quando os dados de cada página ficam organizados e abertos.
